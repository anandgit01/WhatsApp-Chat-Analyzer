# 💬 WhatsApp Chat Analyzer

A privacy-first WhatsApp chat analytics platform that transforms exported WhatsApp conversations into interactive insights, statistics, and visualizations.

## Features

### 💬 General Chat Analyzer

Analyze personal, group, family, and work conversations with:

* Message statistics
* Participant comparisons
* Activity timelines
* Response-time analysis
* Conversation starter tracking
* Monthly and weekly trends
* Activity heatmaps
* Word frequency analysis
* Interactive charts
* PDF report export

### 💕 Couple Chat Story

A relationship-focused experience designed for couples.

Features include:

* Bond Score calculation
* Head-to-head comparisons
* Reply speed analysis
* Message balance insights
* Conversation streaks
* Fun facts and milestones
* Activity trends
* Personalized relationship summary
* Beautiful visualizations

## Privacy First

🔒 All chat processing happens locally in your browser.

* No data is uploaded
* No servers are used
* No chat history is stored
* No account required

Your WhatsApp export never leaves your device.

---

## How to Use

### Export Your WhatsApp Chat

1. Open WhatsApp
2. Open the desired chat
3. Tap **⋮ → More → Export Chat**
4. Select **Without Media**
5. Download the `.txt` file

### Analyze

1. Open ChatStory
2. Upload the exported `.txt` file
3. Explore your insights instantly

## Why ChatStory?

Most chat analyzers require uploading personal conversations to external servers.

ChatStory takes a different approach:

* 100% client-side processing
* No backend infrastructure
* No data collection
* Fast analysis
* Works directly in the browser
* Completely free
